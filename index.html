HTTP: The Web's Rulebook

Research by Tajmah Taylor

Abstract. Every time you open a web page, stream a video or use an app, your device and a distant server follow a shared set of rules called HTTP (HyperText Transfer Protocol). This site explains those rules in plain language, using a restaurant analogy: how a request is made, what the server's reply means, why plain HTTP is not safe, and how the protocol grew from HTTP/0.9 in 1991 to HTTP/3 today.

Why study HTTP?

Without HTTP, your browser wouldn't know how to request a web page, and web servers wouldn't know how to deliver HTML, images, or video to your screen.

HTTP sits underneath nearly everything a web developer builds, so understanding it makes HTML, CSS, JavaScript and debugging much easier to reason about.
